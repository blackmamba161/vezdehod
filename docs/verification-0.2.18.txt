Reproduction (explicitly choose the connected test device; stop its working VPN first):
python3 tests/device_safety.py --adb /path/to/adb --serial DEVICE safety-018
Other supported modes are listed by --help. Reports stay under private/device-tests.
The memory guard samples the main process only; this is not an all-process peak guarantee.
These checks do not certify all devices, operators, mobile network transitions or long-term stability.

Release architecture selection: ARMv7 ignores incompatible ARM64-only assets; ARM64 prefers its smaller native asset, independent of release-asset order. Downloaded APKs must include both native engines for a supported ABI.
